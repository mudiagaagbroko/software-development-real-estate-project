# Real Estate Website

## Project Overview

A front-end real estate website developed as part of the Mobile and Web Programming course for the Postgraduate Diploma programme at Nile University of Nigeria (2022-2023).

The project demonstrates the use of HTML and CSS to create a real estate web interface, focusing on layout, styling, and property presentation.
